Remote LLM Connection (SSH / HTTP API)

Any remote LLM agent or machine can query this observer over SSH port-forwarding or standard HTTP JSON endpoints: 

# 1. List all open desktop windows (including background/minimized)
curl http://127.0.0.1:8765/api/windows

# 2. Extract pruned LLM YAML + full off-screen text buffers for a window
curl "http://127.0.0.1:8765/api/inspect/ChatGPT?max_depth=9"

# 3. Stream live desktop change events over WebSocket
wscat -c ws://127.0.0.1:8765/ws/events

Key Technical Breakthroughs Implemented Here

  • WinSta0\Default Desktop Bridge: Uses OpenDesktopW("Default") + SetThreadDesktop so background daemons, SSH sessions, and sandboxed agents can still inspect the user's live interactive GUI desktop.
  • UIA CacheRequest Batching: Fetches control role, name, focus, offscreen state, and pattern availability in a single cross-process COM call per node.
  • Zero Focus / Zero Input Guarantee: Never calls SetFocus, Invoke, or Scroll—100% passive observation.
